# Machine Learning Assignment 2

**Roll Number:** P26AI0002

Implementation of:

- Decision Tree baseline
- Bagging from scratch
- Multiclass SAMME AdaBoost from scratch
- Robustness evaluation using masked faces
- Measured bias-variance experiments

## Dataset

Olivetti Faces:

- 40 identities
- 10 images per identity
- 64 x 64 grayscale images

Random seed: `260002`

Per identity:

- 6 train
- 2 validation
- 2 test

The exact split is stored in `split.npz`.

## Main Files

`p26ai0002_assignment.ipynb` - complete implementation and experiments

`split.npz` - fixed train/validation/test split

`config.json` - frozen experimental settings

`figures/` - figures used in the report

`scripts/generate_figures.py` - figure generation code

`logs/final_results.txt` - final measured results

`environment/requirements.txt` - exact Python package versions

## Reproduction

From the repository root:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r environment\requirements.txt

jupyter nbconvert `
    --to notebook `
    --execute p26ai0002_assignment.ipynb `
    --output p26ai0002_assignment_executed.ipynb `
    --ExecutePreprocessor.timeout=-1
```

## Regenerating figures

All figures are generated by the plotting cells in the main notebook.

To rerun the complete notebook and regenerate all figures:

```powershell
python scripts\generate_figures.py
```
